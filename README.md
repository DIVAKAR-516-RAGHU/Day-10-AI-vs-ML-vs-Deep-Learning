# AI vs ML vs Deep Learning

## Day 10 Internship Task

### Objective

This project explains the relationship and differences between
Artificial Intelligence (AI), Machine Learning (ML), and Deep
Learning (DL).

## Technologies Used

- Python
- Jupyter Notebook
- Markdown
- Scikit-learn
- NumPy

## Concepts Covered

### Artificial Intelligence

AI is the broader field of creating systems capable of performing
tasks that normally require human intelligence.

### Machine Learning

ML is a subset of AI that enables computers to learn patterns from
data and make predictions or decisions.

### Deep Learning

DL is a subset of ML that uses multi-layer neural networks to learn
complex patterns.

## Relationship

AI
└── Machine Learning
    └── Deep Learning

## Real-World Examples

| Technology | Example |
|---|---|
| AI | Virtual Assistants |
| ML | Recommendation Systems |
| DL | Face Recognition |

## Comparison

| Feature | AI | ML | DL |
|---|---|---|---|
| Scope | Broad | Subset of AI | Subset of ML |
| Learning | May or may not learn | Learns from data | Learns using neural networks |
| Data | Varies | Usually required | Usually large amounts |
| Example | Virtual Assistant | Recommendation System | Face Recognition |

## Conclusion

AI is the broader concept, ML is a subset of AI, and DL is a subset
of ML. Each technology has different applications and requirements.
